Copy web tables in six formats

Status

Ready

How to copy

Right-click a table cell, open Copy table as, then pick a format:

  • Rich text pastes as a formatted table in spreadsheets, documents and email
  • HTML code the table's HTML markup as plain text, for code editors
  • Markdown
  • Plain text
  • CSV
  • JSON an array of objects keyed by the header row

Works on semantic <table> elements only, not on tables inside cross-origin frames.
