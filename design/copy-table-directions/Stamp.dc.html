The honest cost

It is loud, for a tool whose entire pitch is that it takes nothing and keeps nothing. The violet runs about twice the chroma of the other two directions, and a saturated block is the most visible thing in the toolbar whether or not the user is thinking about tables.

It is also the mark with the least room left. Blueprint and Ledger can add rules, columns and states as the extension grows; a filled block is already at capacity, so a second format or a busy state has nowhere to live inside it. Saturated violet is a dated color faster than a graphite or a terracotta is.

Pick this only if you are willing to be the loudest thing in the toolbar to be found again.
