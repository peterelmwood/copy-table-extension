Status · Version 1.0.0 system mono

The board pitched Space Grotesk and JetBrains Mono. Neither ships. The extension declares no network destinations, so a Google Fonts link would break the privacy claim outright, and embedding two faces would add more weight to a reviewed package than the typefaces are worth here. Blueprint's character was never the typeface — it is the hairline rules, the graphite, and the mono labels, all of which survive on system stacks.

The board drew icons in the toast; they are not there. This element is injected into whatever page the user right-clicked, so it stays a single text-only node with no child elements. A steel rule for success and an amber one for failure carry the status instead — which the old toast did not distinguish at all.

One cost the board named that no longer applies

Blueprint was charged two icon files for a light and a dark asset. It does ship two files, but they are the 48 and 16 optical cuts, not a theme pair: each one carries its own prefers-color-scheme block and handles both toolbars. Masking the duplicate instead of painting over it removed the background assumption at the same time. The remaining honest cost stands — hairlines still soften at 16px, and the 16 cut is a reduced drawing.
